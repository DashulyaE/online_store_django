# Интернет-магазин 
## Описание проекта:
Данное приложение находится на этапе разработки

## Установка:

1. Клонируйте проект в свой репозиторий по ссылке:
```
git clone github.com/DashulyaE/online_store_django
```

## Реализованы задачи проекта:
1. Создана директория для проекта и настроено виртуальное окружение.
Все зависимости для виртуального окружения хранятся в файле pyproject.toml 
2. Инициализирован новый проект Django внутри этой директории
3. Создано приложение catalog
4. Настроена маршрутизация для нового приложения
4. Созданы 2 HTML-шаблона: для домашней страницы и для страницы с контактной информацией.
5. Для стилизации страниц использован статический файл со стилями из Bootstrap
6. Реализована форма обратной связи на странице контактов и
настроена обработка данных формы в контроллере, 
чтобы отображать сообщение об успешной отправке данных
## Инструкция по работе с программой:
- Папка *templates* содержит HTML-шаблоны 
- Папка *static* содержит статический файл стилей, который используется для стилизации шаблонов
- Для запуска сервера используйте команду:

```
python manage.py runserver
```
- Перейдите по ссылке, появившейся в консоли после
запуска серевра, например: http://127.0.0.1:8000/
- В браузере откроется домашняя страница с примененными стилями
- При переходе на страницу *Контакты* и внесении данных в форму обратной связи
и их отправке, пользователю выдается сообщение об успешной отправки этих данных.
- Для остановки сервера используйте в консоли сочетание клавиш Ctrl+C
